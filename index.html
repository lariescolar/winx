Perguntas Frequentes

O que é este site?

Este é um site institucional desenvolvido como atividade do Módulo 3 utilizando Tailwind CSS e DaisyUI.

Quais tecnologias foram utilizadas?

O projeto utiliza HTML, Tailwind CSS e componentes da biblioteca DaisyUI.

Como posso entrar em contato?

Você pode entrar em contato através dos canais de comunicação disponibilizados no rodapé do site.

O site funciona em celulares?

Sim. O layout foi desenvolvido para funcionar em celulares, tablets e computadores.
